Documentation
=============

These documents are expected to be distributed to others.
Edit all .docx documents inside Word and not Google Docs or Office Live, and turn Track Changes ON.

Released versions should include a PDF version.
 
Whenever a new or updated version is released, a copy of the pdf should be called eCX_start_up_guide_current.pdf. This file is sent out with eCX invitations to new users.
